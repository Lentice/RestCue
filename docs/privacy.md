# Privacy baseline

RestCue 預設只在本機處理與保存資料。

不蒐集鍵盤輸入內容、剪貼簿、畫面、window title、網址或文件名稱。前景 process name 的統計記錄預設關閉，僅在使用者明確啟用後保存。日誌不得意外包含上述資料。

RestCue 是休息提醒工具，不是醫療器材，也不提供診斷或治療建議。

## 資料清除與匯出

使用者可透過「匯出／清除資料」視窗執行以下操作：

- **匯出使用記錄**：將 `usage_events` 匯出為 JSON 檔，僅含已允許的欄位（事件 ID、時間、類型、提醒結果、債務等級）。前景程式名稱、視窗標題、鍵盤輸入、剪貼簿、畫面、網址、文件名稱等永不包含在匯出資料中。
- **清除使用記錄**：執行 `DELETE FROM usage_events`（在 SQLite transaction 內），刪除全部使用記錄，不影響設定。清除後立即生效，已開視窗需重新開啟以顯示更新。
- **重設設定**：恢復所有設定為預設值（含 `CollectForegroundProcessNames = false`），不影響使用記錄。部分設定將於下次啟動時生效。

### 技術限制

- SQLite 的 `DELETE` 只標記列為已刪除，不保證物理抹除；資料庫檔案大小不變。若需回收空間，使用者可手動執行 `VACUUM`；本工具不自動執行 `VACUUM`，以免在交易外操作引入複雜狀態。
- 清除操作後，`-wal`（Write-Ahead Log）與 `-shm`（Shared Memory）檔案可能殘留。這些檔案不含邏輯上已刪除的資料，但若需徹底移除，可刪除 `.db` 檔（連同設定一併移除）或手動執行 `VACUUM`。
